Dev dependencies are packages required only during development, such as testing, linting, type checking, or automatic server restarts. They are not needed for running the application in production and are installed using npm install -D <package>.

"npm i -D @types/express @types/mongoose @types/dotenv nodemon concurrently"

@types/express - TypeScript definitions for Express.
@types/mongoose - TypeScript definitions for Mongoose .
@types/dotenv - Type definitions for dotenv .
nodemon - Automatically restarts the server when code changes.
concurrently - Runs multiple commands at the same time (e.g., frontend + backend together).

Scripts in package.json:

build: "tsc" – Runs the TypeScript Compiler (tsc) to compile all .ts files into .js files (usually inside the dist folder) for execution by Node.js.

start: "node dist/index.js" – Starts the application by running the compiled JavaScript file using the Node.js runtime. This is typically used in production.

dev: "concurrently \"tsc -w\" \"nodemon dist/index.js\"" – Used during development. tsc -w continuously watches TypeScript files and recompiles them on every save, while nodemon watches the compiled JavaScript files and automatically restarts the server whenever changes are detected. concurrently allows both commands to run simultaneously in a single terminal.

A queue stores messages until they are processed.

Role: Holds messages temporarily.

Producer

The service that sends messages to RabbitMQ.

Role: Creates and sends messages.

Consumer

The service that receives messages from RabbitMQ.

Role: Reads and processes messages.

Message
